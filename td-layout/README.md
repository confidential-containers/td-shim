# td-layout

A `no_std` crate that defines build-time and runtime memory layouts for the TD-Shim binary in Intel TDX Confidential Computing environments, providing constants, types, and utilities for two distinct layout contexts:

- **Build-time layout**: the fixed region map of the 16 MB TD-Shim firmware image as it appears on disk and when loaded into memory at `0xFF000000`.
- **Runtime layout**: the dynamic memory map established at boot, with two variants (`exec` and `linux`) describing how regions are allocated within low memory (below TOLM).

The layout constants in `build_time` and `runtime/` are auto-generated by the `td-layout-config` tool and should not be edited manually.

## Modules

### `build_time`

Constants for the firmware image layout (offsets, sizes, and load-time base addresses):

| Region         | Offset       | Size      | Load Base      |
|----------------|-------------|-----------|----------------|
| `CONFIG`       | `0x000000`  | 256 kB    | `0xFF000000`   |
| `MAILBOX`      | `0x040000`  | 4 kB      | `0xFF040000`   |
| `TEMP_STACK`   | `0x041000`  | 128 kB    | `0xFF041000`   |
| `TEMP_HEAP`    | `0x061000`  | 128 kB    | `0xFF061000`   |
| `PAYLOAD`      | `0x081000`  | ~12.18 MB | `0xFF081000`   |
| `METADATA`     | `0xCAE000`  | 4 kB      | `0xFFCAE000`   |
| `IPL`          | `0xCAF000`  | ~3.29 MB  | `0xFFCAF000`   |
| `RESET_VECTOR` | `0xFF8000`  | 32 kB     | `0xFFFF8000`   |

Total image size: 16 MB (`0x1000000`).

### `runtime`

Two pre-defined runtime memory layout configurations, each providing a `MEMORY_LAYOUT_CONFIG` slice suitable for use with `RuntimeMemoryLayout::new()`:

- **`runtime::exec`** — layout for general execution payloads.
  Regions: `Bootloader`, `TdHob`, `Acpi`, `Payload`, `PayloadPageTable`, `RelocatedMailbox`, `EventLog`.
- **`runtime::linux`** — layout for Linux payloads.
  Adds `UnacceptedMemoryBitmap` and `PayloadParameter` regions.

### `mailbox`

Defines `TdxMpWakeupMailbox`, a 16-byte `repr(C)` structure used in the Intel TDX multi-processor wake-up protocol.

```rust
pub struct TdxMpWakeupMailbox {
    pub command: u16,
    pub rsvd: u16,
    pub apic_id: u32,
    pub wakeup_vector: u64,
}
```

### `memslice`

`SliceType` enum names the known memory regions (e.g. `Config`, `MailBox`, `ShimPayload`, `Payload`, `EventLog`, etc.).
The free functions `get_mem_slice` and `get_mem_slice_mut` return raw slices to fixed build-time regions by `SliceType`.

## Key Types

### `RuntimeMemoryLayout`

Computes base addresses for all runtime regions from a `LayoutConfig` slice and a top-of-low-memory (`tolm`) value.
`"Memory"`-typed regions are allocated upward from address zero; all other types (`"Reserved"`, `"Nvs"`, `"Acpi"`) are allocated downward from `tolm`.

```rust
let layout = RuntimeMemoryLayout::new(tolm, runtime::exec::MEMORY_LAYOUT_CONFIG).unwrap();
let region = layout.get_region(SliceType::Payload).unwrap();
let slice  = unsafe { layout.get_mem_slice(SliceType::EventLog) };
```

Supports up to 32 regions (`MAX_RUNTIME_LAYOUT_REGION`).

### `TD_PAYLOAD_PARTIAL_ACCEPT_MEMORY_SIZE`

Constant (`0x10000_0000`, 256 MB) indicating the chunk size for partial memory acceptance during TD initialization.

## Cargo Features

| Feature       | Effect                                      |
|---------------|---------------------------------------------|
| `no-config`   | Disables the `Config` region at build time  |
| `no-mailbox`  | Disables the `MailBox` region at build time |
